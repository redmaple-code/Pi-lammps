# 1IEP / Imatinib 真实重对接方案

案例为 2026-11-17 的本地工具部署与方法验证。研究问题是从配体分子图生成新初始构象后，当前 Vina 工作流能否恢复公开教程中的参考结合姿态。

## 输入和准备

受体与配体取自 AutoDock Vina 官方 basic_docking 数据目录，固定提交为 `bb64e5e26b520569a86360d69248069b5e665b3f`。文件为 `1iep_receptorH.pdb` 与 `1iep_ligand.sdf`，下载记录保存 URL、时间和 SHA-256。

采用教程提供的单一受体与配体化学态。先检查分子键级、原子数、形式电荷和坐标。参考 SDF 保留原样，搜索初态从其分子图经 RDKit ETKDG 重新嵌入并做适用的力场优化。准备阶段将这项化学态选择和初态生成方式写入回执。

受体采用 Meeko 生成 PDBQT，配体采用 Meeko 保存原子恢复信息。搜索框中心为 `(15.190,53.903,16.917)` Å，尺寸为 `(20,20,20)` Å。受体维持教程坐标，输出参考 RMSD 在固定受体坐标系中按化学对称映射计算。

## 预定搜索和分析

Vina 1.2.7，评分函数 vina，exhaustiveness=32，最多20个模式，energy_range=3 kcal/mol。种子预定为104729、130363、155921，每次使用4个CPU线程。单次超时900秒，三个运行分别保存输入摘要、argv、起止时间、退出码、日志和输出。

分析全部输出模式，分别报告各种子的top1参考重原子RMSD、best-of-5 RMSD、评分、姿态数量和严重空间冲突提示。参考比较使用原始教程配体，保持受体坐标，计算配体原位的对称重原子RMSD。

初始方法验证目标采用重原子RMSD≤2 Å。分别汇报top1命中比例和best-of-5命中比例，三个种子中top1命中至少两个为本案例的点估计目标。种子和判据在求解前固定，结果未达目标时如实登记。

## 运行边界

本案例使用公开的已加氢教程受体。全受体质子化、结合水选择和多化学态敏感性属于后续验证范围。对接分数、参考姿态恢复、实验亲和力和生物活性各自记录依据。

部署验证在独立本地Python环境开展，科学原始输入、运行与分析保存于本目录。案例脚本直接调用实际工具，通用产品内核与独立科学审查的集成状态记录在交付报告。
