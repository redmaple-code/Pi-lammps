# 对接工具配置与适配要求

| 能力 | 候选工具 | 关键输入/输出 | 集成验证 |
|---|---|---|---|
| 化学身份、构象和映射 | RDKit | SDF/SMILES、原子映射→状态台账与构象 | 立体、电荷、键级和对称映射往返 |
| 质子化/互变异构选择 | Molscrub 或有依据的状态选择方法 | pH、限制与母体→带来源状态集 | 状态覆盖、失败与截断记录 |
| 受体/配体准备 | Meeko，所需补氢/结构修复工具按版本登记 | 结构、模板、准备决定→PDBQT与恢复映射 | 残基、原子类型、转动键、化学导出 |
| 对接搜索 | AutoDock Vina | 冻结的受体、配体、box、scoring和搜索参数→pose/log | 种子、真实运行、版本、输出完整性 |
| 姿态/计量 | RDKit 与经验证的分析器 | 原子映射、参考、pose→RMSD、簇、接触和排名 | 固定受体框架、对称性、分母、排序 |
| 展示 | PyMOL 或兼容结构查看器，绘图库 | 分子和指标→图表 | 受体/配体/姿态身份和位点视图 |

适配器 ID 是本包定义的目标接口。部署记录实际安装版本、可执行文件/API、许可证/来源、平台、线程与环境摘要。manifest 中工具范围 `*` 表示当前尚待锁定，形成执行计划时需解析为经过验证的精确版本。

运行矩阵逐项绑定 receptorId、parentId、stateId、conformerId、seed、protocolDigest、runId 和 operationId。恢复时按 operationId 对账。种子相同的重复投递关联既有操作，改变输入需新运行身份。

准备错误返回结构化化学问题和原始日志。批量失败保留每个母体/状态的失败原因。分析器保持源分子映射，使用工具原生输出时保存对应恢复信息。

运行就绪检查涉及当前路线的适配器、原始资料、控制要求和输出需求。精确版本、真实基准和平台调用回执写入验证记录后，更新对应绑定状态。
