# 跨领域仿真开发规范与文档包

版本：1.0.0；日期：2026-11-17；交付类型：开发规范基线。用户已确认通用化方向并授权落实文档；产品实现、真实仿真、部署和发布均未开展。

## 规范效力

“必须/不得”是实现验收要求；“应”表示默认做法，例外需记录理由与影响；“可”是可选能力。正文为行为语义权威，Schema 是结构约束权威；二者冲突时记录规范缺陷并修正，不能选择宽松的一方放行。

本包细化[已确认通用设计](../跨领域通用仿真工作流与领域包设计.md)。[旧迁移方案](../迁移方案.md)继续作为 Red Maple 接入和 LAMMPS 迁移依据；[旧 92 项矩阵](../功能迁移与验收矩阵.md)继续约束 LAMMPS 包。差异按 [00 文档](00-scope-and-decisions.md)显式划界，不把旧要求整体废弃。

本目录中的流程、接口和目录名是待开发契约。本文不提供已存在的 `sim validate` 等虚构命令。结构检查通过、规范覆盖、实现完成、真实运行和科学验收分别记账。
