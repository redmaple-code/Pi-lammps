# 07 科学验证、计量与交付规范

## 1. 四类事实分别表达

| 事实 | 必须回答 | 不足时 |
|---|---|---|
| 执行完成 | 是否真正调用指定工具，完成所需计算并取得完整输出？ | failed/unknown/缺输出，不报真实完成 |
| 数值与实现验证 | 方程/规则实现及求解误差是否满足当前目的？ | 报未通过或证据不足 |
| 模型验证 | 对目标现实问题的模型假设是否得到适用证据支持？ | 报未验证/范围受限，不能借数值收敛代替 |
| 任务验收 | 既定指标与交付项是否满足？ | 分项 met/notMet/cannotCompute/borderline |

纯方法研究或工具验证可以在约定范围内不做现实预测验证，但必须明确 notApplicable 的范围和理由；不能靠删验证项宣称全面可信。校准与独立验证数据必须区分，拟合误差不能直接作为泛化误差。

## 2. 问题定义与可检验特征

方案必须描述目标、对象、系统边界、尺度、模型假设、参数、条件、求解/试验方法、验收、资源和风险。每项必需特征绑定 requiredStage、criticality、verificationMethod 和 evidenceRequirements。

特征可为物理实体、接触/边界、网络行为、数据覆盖或事件规则，不强制每个任务都有晶体、几何或网格。声明/注释不是实现证据，应检查实际结构、配置或行为。

## 3. 指标契约与输出闭合

每个指标必须具备定义、量纲/单位、方向/分量、参考/符号、实体/空间选择、时间/事件窗口、采样频率、统计方式、算法版本、误差/不确定性、参考依据和验收规则。

运行前建立 `criterion → metric → requiredData → producerStage/runOutput` 映射，核对输出字段、频率、分辨率、存储与精度。输出不足阻止正式运行就绪，或显式缩小已授权交付范围；不能等待运行后用外部参考值补成结果。

验收阈值、统计窗和参考在生产运行前锁定。必要修改产生新版本，说明理由和对既有结果的影响。不能选择“最好看的窗口”隐藏不稳定或未达标。

## 4. 数值与统计检查库

| 检查族 | 适用条件与注意 |
|---|---|
| 网格/粒子数/域尺寸 | 分清离散误差、有限尺寸与边界影响，不把它们合并成单个误差 |
| 时间步与迭代收敛 | 非线性残差、时间离散、目标量稳定性分别评估 |
| 守恒与平衡 | 核对控制体、源项、边界功/通量和预期非守恒机制 |
| 随机重复与采样 | 独立种子、预热期、自相关、有效样本和置信区间 |
| 解析/制造解/基准 | 记录匹配的方程、边界、假设和比较范数 |
| 敏感性与不确定性 | 参数、测量、数值和模型形式误差分开，避免重复计入 |
| 校准与反演 | 目标函数、约束、训练/验证数据、可辨识性和停止规则 |

不存在通用残差或误差阈值。领域包给出方法与默认依据，任务按用途锁定容差。奇异点应力不应仅靠无限网格细化追求峰值收敛；单一随机种子的结果也不能代替统计区间。

## 5. 多场与多尺度耦合

耦合定义包含子包锁、交换量、源/目标关联、单位、坐标、方向、插值/投影/均匀化、时间推进、松弛、收敛、误差和失败恢复策略。

单向传递需保留参数适用工况和不确定性；双向传递需检查界面量和必要的守恒；单体求解需验证联合模型与变量关系。不能把转换后同名字段自动视为同物理量。

同步恢复绑定一组一致的子模型检查点和交换序号。某子模型失败时停止后续依赖，保留各子模型实际状态；只有一致状态重建后恢复，不各取最新 checkpoint。

## 6. 三类真实基准的准备要求

下列是未来验证方案，不是本轮运行结果，也不提供未经核实的默认参数。

| 类型 | 建议最小任务 | 执行前要冻结的依据 | 真实验收证据 |
|---|---|---|---|
| 微观 | 经过核验的小型粒子体系演化，检查适用的能量和采样行为 | 势/参数来源、单位、积分方法、边界、初态和容差 | 真实轨迹、工具版本、能量/时间步或基准比较，以及错映射反例 |
| 宏观 | 小变形弹性梁或其它有解析依据的结构案例 | 几何、载荷、约束、本构、解析假设、离散方案、比较位置和容差 | 真实求解数据、位移比较、平衡及网格研究，另有欠约束反例 |
| 离散事件 | 稳定 M/M/1 排队模型 | 泊松到达、指数服务、独立性、先来先服务、λ<μ、预热/种子/统计方案 | 多次真实事件运行及等待时间区间；检查 λ≥μ 不被误判稳态 |

M/M/1 在上述假设下，平均排队等待时间为 `λ/[μ(μ−λ)]`，平均系统逗留时间为 `1/(μ−λ)`；二者必须分开。引用正式参考并冻结单位/估计方法后，才能作为项目验收依据。仅模拟适配器返回这些解析值不算真实事件仿真。

## 7. 图像与报告

图表必须绑定实际数据、run、analysis、指标定义、工具版本、视图选择和图像核验。生成脚本只记 scriptOnly；存在 PNG 且尺寸正确不能代替打开核对对象、帧、ROI、色标、单位和图注。

报告逐项列：范围、方案/包锁、输入审查、真实运行、数值验证、模型验证、指标验收、图像状态、未完成项、限制和复现入口。允许同时出现“运行完成、任务未达标、知识候选待审”。

完整复现不等于逐位相同。记录随机种子、并行设置和环境，按领域定义数值容差或统计复现范围；无法确定来源的旧结果应限定结论，不倒推编造参数。
