# 有限元动力学工具配置与适配要求

| 能力 | 候选工具 | 核心契约 | 集成验证 |
|---|---|---|---|
| 几何与网格 | Gmsh、受控CAD/网格导入 | 稳定实体、节点/单元/集合、坐标、网格质量 | 体积/质量、映射、支承/加载面 |
| 模态 | CalculiX | 输入、质量/刚度、预载、约束→频率/振型与必要存储 | 刚体模态、归一化、版本与模态数据 |
| 隐式瞬态 | CalculiX | 初态、阻尼、载荷、时间/输出→时程、场和收支 | 直接积分、非线性与输出兼容 |
| 谐响应 | CalculiX | 当前模态基础、频段、阻尼、激励→复数场 | eig文件、幅相、截断、基底运动能力 |
| 显式冲击 | CalculiX 显式候选或 LS-DYNA 候选 | 材料/接触、初速度、稳定步长和控制→动态结果 | 各版本单元/接触支持、人工处理与能量 |
| 分析 | Python/SciPy 及受控解析器 | 原生结果与位置/坐标/时频→指标 | 复数/单位、原生能量定义、峰值/采样 |
| 展示 | cgx、ParaView 兼容转换或其它经验证查看器 | 场、网格、时间/模态→图像/动画 | 转换损失、位移倍率和实际时间 |

CalculiX 的 `.dat`、`.frd` 和按需产生的 `.eig` 具有不同用途。适配器记录各步骤实际输出，并按版本核对所需字段。模态存储文件必须绑定模型、边界、预载、工具版本和摘要。

LS-DYNA 作为显式冲击工具候选，接入时另行核对版本手册、材料/单元/接触卡和许可证。当前包给出的能力 ID、状态和数据要求供适配实现，具体输入卡在实施时生成并验证。

`requiredCapabilities` 表示四条路线共同需要的能力。每条路线的求解、检查和分析能力由其阶段图追加。工具配置给出完整候选绑定集合，当前任务按实际能力闭包判断就绪，避免因无关路线缺工具阻止可执行任务。

SI 示例采用 kg、m、s、N、Pa。导入其它单位模型时登记转换，质量、密度、转动惯量和阻尼量纲一并转换。载荷时程保持实际单位，输入适配器显式记录幅值归一化和时间基准。

真实执行保留 argv/API、workdir、输入闭包、线程/求解器库、外部作业身份和日志。监测超时、取消、输出缺失和未知提交。重启检查点需与原始模型、时刻及外部状态一致。

研究适配器提供 `fem.study.prepare`、`fem.study.solve` 和 `fem.verification.aggregate`。前者根据冻结的变体表和 iterationIndex 生成研究输入，中者按当前 taskType 与 profile 分配实际求解并跟踪子作业，后者将样本汇总为累计验证报告。谐响应的子运行包含与变体一致的模态重建。每次外部调用都占用案例预算并记录独立身份。
