# 领域仿真工作流包

版本 0.1.0，2026-11-17。按跨领域开发规范补充两套可修改的领域工作流，交付范围包括科学方法、知识来源、数据契约、工具配置、阶段图、检查、失败处理和验证方案。

| 工作流包 | 任务范围 | 默认工具路线 | 入口 |
|---|---|---|---|
| small-molecule-docking | 蛋白质与小分子非共价对接、已知位点候选排序、回顾性筛选评估 | RDKit、Meeko、AutoDock Vina | [小分子对接工作流](small-molecule-docking/README.md) |
| fem-dynamics | 模态、隐式瞬态、线性谐响应、显式冲击 | Gmsh、CalculiX、科学分析工具，显式路线另选经验证工具配置 | [有限元动力学工作流](fem-dynamics/README.md) |

## 使用方式

1. 从包的 README 选择任务路线和适用范围。
2. 按 `problem.schema.json` 填写任务，`examples/task.json` 提供可校验的演示配置。
3. 在 `manifest.json` 选择工作流及工具配置，读取模型、检查、指标和试验协议。
4. 补齐实际输入、精确工具版本与适配器验证记录，形成当前案例的锁定计划。
5. 按验证目录中的正常案例和反例开展集成与科学验收。

每包的资源文件均有摘要，可直接核对内容。工具绑定保留 unverified，验证案例记录 planned。文档检查与任务 schema 检查记录在 [检查回执](evidence/validation.json)。

小分子包已更新为0.1.1-draft，支持有符号随机种子和固定已有化学态。真实工具案例见[官方1IEP输入输出复现](../../work/cases/vina-official-1iep-20261118/README.md)：固定官方输入及参考输出，提供实际计算、逐姿态比较和搜索预算研究。案例脚本完成了领域阶段的证据映射，平台适配器的集成认证仍保持待验收状态。

## 工件与实现交接

`manifest.json` 遵循现有领域包结构 Schema。各包资源使用 JSON，领域方法和阶段说明使用 Markdown。检查器、能力和角色 ID 定义了后续实现所需接口，开发者据此接入通用内核和求解器。

选择蛋白质受体、小分子非共价对接、候选工具和四种动力学路线属于本轮补齐的工程范围。实际生物靶标、结构、材料、几何和任务阈值由具体案例提供。

通用开发依据见 [开发规范入口](../development-spec/README.md)。
