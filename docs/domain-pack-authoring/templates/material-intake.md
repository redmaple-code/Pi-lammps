# 资料采集表

| 字段 | 用户资料或系统登记 |
|---|---|
| 批次/资料身份 | 待登记 |
| 标题、作者/机构、版本/日期 | 待提供或从资料提取 |
| 原始位置与取得方式 | 文件、地址、会话摘录或待取得项 |
| 材料类型 | 案例、规范、报告、数据、日志、口述等 |
| 你希望它帮助哪个任务/判断 | 待用户说明 |
| 最相关页段/条款/步骤 | 可先由用户指出，再由系统定位 |
| 读取范围与解析问题 | 系统记录 |
| 适用行业、对象、工况、工具版本 | 已知项与待核项分别填写 |
| 使用/导出范围 | 沿资料归属与用户授权登记 |
| 建议标签与理由 | 系统提议，用户可修改 |
| 关联案例、知识与后续问题 | 采用稳定引用 |

资料可先登记，后续逐步补齐。原始文件、提取文本和用户说明分别保留。
