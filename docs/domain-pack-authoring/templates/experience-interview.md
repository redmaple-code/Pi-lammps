# 经验访谈表

| 追问 | 用户回答/来源/待核项 |
|---|---|
| 这是哪次任务，目标和环境是什么？ | 待用户说明 |
| 你观察到哪个现象？ | 待用户说明 |
| 哪个信号让你决定改变？ | 待用户说明 |
| 你考虑了什么选择？为什么这样选？ | 待用户说明 |
| 实际改了什么？同时还有哪些变化？ | 待用户说明 |
| 实际结果怎样，怎样测量/评价？ | 待用户说明 |
| 有没有日志、输入、报告或口述定位？ | 待提供或登记口述来源 |
| 你认为原因是什么，哪些部分还不能确定？ | 观察与解释分别记录 |
| 哪些条件下适用？有哪些例外/失败？ | 待用户说明 |
| 下次应在什么步骤提醒谁做什么？ | 待用户选择用途 |
| 哪些内容可纳入共享包？ | 待按使用范围决定 |

系统按已知内容选择当前最有价值的追问，保存候选 practice/observation/claim 以及标签建议。用户可以逐步回答、修订或暂缓。
