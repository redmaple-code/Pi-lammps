# 制作内容审阅清单

| 对象 | 审阅要点 | 决定与证据 |
|---|---|---|
| 原始资料 | 身份、版本、读取范围、使用/导出范围可定位 | 待记录 |
| 标签 | 语义、定义、同名异义、目标片段与用户用语一致 | 待记录 |
| 案例与经验 | 观察、动作、归因、条件、例外和结果分开且可核查 | 待记录 |
| 规范 | 原文属性、项目适用性、效力、阈值与测量定义明确 | 待记录 |
| 知识单元 | 来源、条件、认识状态和使用范围完整 | 待记录 |
| 批次采用 | 主体修订/摘要、差异、例外和决定者明确 | 待记录 |
| 包设计 | 每项绑定依据，输入输出、检查和失败路径可执行 | 待记录 |
| 验证与交接 | 当前范围、实际结果、缺口和下一动作可见 | 待记录 |

可选采用、修改、暂缓或拒绝。采用须说明 referenceOnly、projectPractice、packCandidate 或 activeInScope 的范围。内容修订超出原决定时形成新审阅。
