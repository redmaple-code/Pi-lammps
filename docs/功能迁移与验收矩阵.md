# 功能迁移与验收矩阵

基线：用户《完整仿真工作流设计》2026-11-17；Red Maple `25dec99`；autolammps `feaf7f6`。

这是设计覆盖清单，**下表全部条目当前均为“已设计，迁移尚未实现/验收”**。“复用”指已有基础设施或源资产，不表示目标功能已迁好。开发时每项增加实现 commit、测试场景 ID、实际回执路径、环境、结论和未验证范围。一个测试可关联多项需求，但不得无证据批量标通过。

范围：附件 13 章及同基线源码中核实的补充要求。M0 取得缺失专项文档后只能补充/显式裁决，不静默删减。完成条件为必迁条目全部有有效证据、必需缺件/冲突关闭；明确的外部能力边界单独说明。具体执行授权按任务生效，本表不是运行授权。
