# 领域库初始化功能块实施记录

2026-11-17。用户确认将引导式领域包制作机制接入 Pi-agent，作为独立领域库初始化功能块。

## 已接入行为

新增 `simulation/agent-modules/domain-initialization`，遵守既有 ModuleHost 协议，并接入应用装配、Pi 扩展和 CLI。领域库可创建、持续补充、暂停/恢复，案例与规范可从文本或 PDF 导入，口述可直接登记为来源。

AI 通过具名工具整理知识/标签候选，用户通过宿主界面进行逐项或批次审阅。采用内容绑定候选修订、来源、适用条件及用途，认识状态保留为实际证据支持的状态。工作查询与候选工作台分别返回相应条目。

研究上下文吸收 scholar-apprentice 的知识单元、案例复原、原文核查、边界/反例和经验回注方法。用户的资料和回答驱动当前问题选择，未知/暂缓形成缺口。

## 接入位置

| 文件 | 责任 |
|---|---|
| agent-modules/domain-initialization/index.js | 功能块操作契约、身份与输入检查 |
| service.js | 制作会话、来源、候选、标签/采用、检索和快照 |
| repository.js | 可替换 read/list/save 仓储、当前文件与内存实现 |
| pi-extension.js | /domain-init、三个工具、用户界面、会话恢复和引导上下文 |
| guidance.js、assets | 独立分发的研究方法提示、问题目录和制作 Schema |
| materials.js、privacy.js | 文件/文本/PDF读取及资料边界 |
| host.js、cli.js | 默认宿主装配、审计与离线整理入口 |
| packages/application/index.js | 在本地状态目录打开领域库功能块 |
| packages/runtime-redmaple/index.js | 现有 Pi 扩展装配领域库入口 |
| apps/cli/main.js | 公开命令与具名工具策略接入 |

## 工程决定

制作服务采用可替换仓储协议，当前默认写本机状态目录的 JSON 快照。数据库产品选型保持开放。每次修改进行修订比较与原子发布，导出保留交换 bundle 和操作回执。

用户答复、采用和暂停/恢复使用宿主交互入口提供的 human 身份。模型候选及其标签留待用户决定。资料入口按 personal-twin 规约检查常见联系方式和凭据格式，原始正文不进入模块审计。

普通会话重启可继续已提交状态。强制结束写者后留下的锁有明确的维护恢复方式。当前存储采用单机条件写入，后续后端适配继续遵守相同修订契约。

## 验证与限制

实际命令、结果和证据见 [功能块验证回执](domain-library-initialization-validation.json)。测试包含真正的 Pi SDK 会话，模型响应由受控夹具提供。云模型领域判断和真实用户引导体验仍需在实际资料任务中评估。

当前支持初始化、经验整理和知识采用。完整领域包组装、行业条款专用字段编辑及更多仓储实现列入后续扩展，来源和决定记录可供这些能力衔接。

使用步骤与独立装配方式见 [功能块说明](../../simulation/agent-modules/domain-initialization/README.md)。
