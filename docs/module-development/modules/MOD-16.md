## 4. 实现机制与不变量

350项清单只代表已盘点tracked候选；扫描必需引用闭包和外部数据清单，不以tracked数量假称全库。每资产注明copy/wrap/rewrite/archive/notApplicable及理由/目标/验收。缺raw案例、手册、纠错、势资源和专项设计分别登记影响。旧standalone/team状态冲突不给自动胜者；历史无hash写import-observed而非历史验证。导入前备份、dry-run审阅、事务批次与断点，重复导入相同批次不重复记录。

## 5. 数据、存储与所有权

保留legacyId、sourceCommit/path/rawStatus/reviewerText、importedAt、observedDigest、targetRef、mappingVersion。源保持只读；切换后单一写入方，旧只读入口保留。

不复制其它模块权威状态。跨库操作使用持久操作意图及回执，不声称外部调用与本地事务原子提交。关联元数据必须使用真实输入/版本，不能从“最新文件”猜测。

## 6. 主路径与异常处理

1. 盘点全部必需源与缺口，生成可审阅映射和冲突。
2. 备份并导入候选空间，逐类型/状态/引用核对，不自动发布confirmed。
3. 通过对账后切换写入方；失败恢复备份/停用新入口并留证据。

异常与恢复：不可识别旧值拒绝猜测；重复ID不同内容报冲突；缺件只阻塞依赖该资源的功能。不得补造旧PASS与旧run。

日志仅记录身份、版本、状态、诊断位置和证据引用；敏感源正文、凭证与全历史不进入通用日志。时间/数量等测量保留单位。性能先采基线，尚无已承诺吞吐量或延迟目标。
