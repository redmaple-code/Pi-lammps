- `domains/structural-mechanics/manifest.json、problem/、workflows/、checks/、metrics/`：宏观模型、阶段、检查、计量与来源

本节路径相对拟议simulation工作区根，均待创建。共享ToolPort由MOD11维护；本模块只新增具体领域适配和内容，不能修改通用内核以识别某领域。

## 4. 实现机制与不变量

宏观最小案例选小变形弹性梁等有适用解析依据的任务，冻结几何/本构/约束/载荷、离散、比较位置和容差；工具候选如CalculiX须先核本机/目标环境版本与能力，不能只声称接口可用。事件最小案例为M/M/1，冻结泊松到达/指数服务/独立种子/预热和λ<μ；使用实际事件队列仿真，不让adapter返回理论值充结果。平均排队等待和系统逗留分开计算。两包不强制原子势、网格以外范式的几何阶段或LAMMPS WF编号。发布前具备真实计算、数值/统计与任务证据。

## 5. 数据、存储与所有权

宏观保存节点/单元关联、坐标/单位、位移/反力、网格序列；事件保存到达/服务/离开时间、seed、预热与统计窗口、重复试验分布。模型验证未完成单列，不因理论算例通过宣称所有现实场景有效。

不复制其它模块权威状态。跨库操作使用持久操作意图及回执，不声称外部调用与本地事务原子提交。关联元数据必须使用真实输入/版本，不能从“最新文件”猜测。

## 6. 主路径与异常处理

1. 按draft示例核准真实工具与参考来源，确定最小科学协议和误差预算。
2. 实现两套声明与适配/测量方法，先结构/负例校验再真实计算。
3. 宏观完成离散/平衡和欠约束反例，事件完成多种子统计和非稳态反例，回写各自验证回执。

异常与恢复：缺工具/解析适用性/容差证据只阻塞对应领域；欠约束/λ≥μ不能自动调参数凑通过。两个领域失败不删除原微观验收证据。

日志仅记录身份、版本、状态、诊断位置和证据引用；敏感源正文、凭证与全历史不进入通用日志。时间/数量等测量保留单位。性能先采基线，尚无已承诺吞吐量或延迟目标。
