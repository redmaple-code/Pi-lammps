## 4. 实现机制与不变量

读取回执由文件/检索/提取器适配器提交，绑定实际字节或文本表示和读取区间。fullText/section/abstract/metadata分开；访问到URL不等于读过全文。LAMMPS至少一份相关本地实读案例；通用领域按锁定包政策可用解析/制造解等替代，不能将放宽反灌旧包。manual/correction与case/memory双侧按独立来源分组，不把artifact默认当第二侧。来源相关性、已读、版本固定、是否确认四个维度分别核对。

## 5. 数据、存储与所有权

EvidenceRef保留originGroupId、applicability、location与readReceiptRef；未知来源组标待裁定，不能按文件路径自动计独立。URL可有抓取摘要/时间；不具稳定修订则unfrozen并按规则处理。

不复制其它模块权威状态。跨库操作使用持久操作意图及回执，不声称外部调用与本地事务原子提交。关联元数据必须使用真实输入/版本，不能从“最新文件”猜测。

## 6. 主路径与异常处理

1. 通过KnowledgePort/ArtifactStore取实际内容并生成读回执。
2. 核适用范围、版本、引用位置和证据类型，对同源派生件合并来源组。
3. 返回满足项与缺口，由K2放行判定；不自己更新知识confirmed。

异常与恢复：引用不可达或关键版本改变为EVIDENCE_INSUFFICIENT/ARTIFACT_CHANGED；网络只读重试服从共享规则。来源不充分允许部分说明，不允许PASS。

日志仅记录身份、版本、状态、诊断位置和证据引用；敏感源正文、凭证与全历史不进入通用日志。时间/数量等测量保留单位。性能先采基线，尚无已承诺吞吐量或延迟目标。
