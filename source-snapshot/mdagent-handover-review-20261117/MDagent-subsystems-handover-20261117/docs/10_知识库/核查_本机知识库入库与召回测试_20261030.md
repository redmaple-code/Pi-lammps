## 3. 旧关键词检索召回率、精确率与排序

### 3.1 受控词项测试集

为 8 条新 kind 各指定一个人工 gold query，统计唯一 gold 相关项/查询。实际搜索是 `find_scenario_semantic` 对所有可见 atoms 做空格分词、子串匹配、命中词数排序；没有持久倒排索引。

| Query ID | 查询词 | gold 条目名次 |
|---|---|---:|
| cohesion | `cohesion aperture knowledge unit` | 1 |
| approval | `payload digest binding gate receipt` | 1 |
| consumer | `consumer namespace evidence checklist` | 1 |
| unknown | `applicability unknown mismatch` | 1 |
| catalog | `catalog digest invalidation by_term` | 1 |
| refs | `reference resolver retracted superseded` | 1 |
| card | `projection lifecycle retracted` | 1 |
| authority | `relevance authority separation mismatch` | 1 |

指标按单一 gold 相关项/查询计算：

- Hit@1：**8/8 = 100%**。
- Recall@5：**8/8 = 100%**；Recall@10：**8/8 = 100%**。
- MRR：**1.00**；平均 gold rank：**1.00**。
- Precision@5（固定返回位口径）：每条 query 的 5 个返回位中最多 1 个属于本次唯一 gold，均值 **0.20**；这表示当前测试集合的检索结果包含较多非 gold 候选。另一个“按实际返回数”的均值为 **0.452**，但它会因某 query 返回不足 5 条而变高，不能替代固定@5口径。

相关性定义只针对 8 个新造测试 kind 的唯一 gold 目标；atoms 中原有记录与其它 7 个新 kind 在这个小型检索问题上的“非 gold”，不代表其知识内容本身错误或无关。本测试事实由测试者撰写，故指标不测真理正确率、知识质量、跨领域泛化或外部用户分布。

这个受控测试集刻意在 query 中使用了与测试 facts 相同的高辨识英文词项，只证明当前 substring-overlap 对“已抽取关键词”的表现，不代表真实用户自然语言问句的总体质量。
